# Little by Little (PWA)

A personal workout calendar and cardio log. This version uses browser local storage; data stays on the device/browser and is not synced.

## Files
- index.html
- style.css
- app.js
- manifest.json
- sw.js
- icon.svg

## Deploy
Publish the repository using GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)).

## Note
If already installed on a phone, reload the published site and allow the service worker to update. If the old screen persists, close the app fully and open it again. Local saved data may be browser-origin specific; do not clear website data.
